AI-Powered-OPD-Registration-Medicine-Management-System-
MediSmart AI is an intelligent Healthcare management system that streamlines OPD registration, monitors medicine stock and expiry dates with automated alerts, and includes an AI-powered symptom analysis assistant. The project is designed to improve hospital workforce, reduce medicine wastage, and provide quick preliminary  health guidance .
A short feature list:
🏥 OPD Patient Registration
💊 Medicine Inventory Management
⏰ Low Stock & Expiry Alerts
🤖 AI Symptom Analysis Assistant
📄 PDF Report Generation
💾 SQLite Database Integration
🖥️ Built with Python & KivyMD
